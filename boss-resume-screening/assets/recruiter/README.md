# Boss Helper 招聘复核版 0.1.0

这是在 Ocyss/boss-helper 仓库新增的独立招聘端入口。原版 Vue/WXT 求职功能保留；招聘版独立构建，不需要原项目的子模块和依赖，不包含原版投递流程。

## 已实现
- 在 BOSS 招聘端 `/web/chat/*` 页面显示「候选人复核」浮动面板。
- 读取当前页面及同源 iframe 中已渲染的候选人卡片；可手动粘贴摘要。
- 每行填写技能或工作经验，使用 `|` 提供同义词。展示文字命中原句和待核实项。
- 人工标记、备注、记录过滤、重复摘要去重、CSV 导出。
- 无外部模型、无网络上传、无后台采集、无自动打招呼或录用/淘汰操作。
- 数据只在页面内存保存，刷新或关闭页面会丢失，操作前后注意导出。

## 安装
1. 打开 Chrome 扩展程序页面：`chrome://extensions/`。
2. 开启开发者模式，点击「加载已解压的扩展程序」。
3. 选择本仓库的 `recruiter-dist` 文件夹（不是源码目录，也不是 zip 文件）。
4. 刷新已打开的 BOSS 招聘页面，点击右下角「候选人复核」。
5. 填写技能要求，读取列表，再点击「核对要求」。

本版只在 `https://www.zhipin.com/web/chat/*` 和 `/web/frame/*` 注入内容脚本，没有所有网站访问、通知、存储等额外权限。与商店求职版为不同扩展，可分别管理。

## 构建与验证
```
node recruiter/build.mjs
node --test recruiter/core.test.mjs
node --check recruiter-dist/recruiter.js
```
从仓库根目录启动本机 HTTP 服务，访问 `/recruiter/preview.html`，可用虚构数据验证同源 iframe 读取、去重、人工标记、技能证据和空状态。

## 已知边界
- 这是本地关键词证据核对版，不是 AI 语义评估，不能从 JD 自动生成可靠筛选规则。
- “已提及”仅表示原文包含该词。例如“没有 SQL 经验”仍会展示原句，必须由人解读。期望职位也可能命中关键词，不等于实际工作经历。
- 仅覆盖已加载列表摘要，不打开简历详情、不遍历全部候选人。
- 页面选择器是兼容性启发式识别，BOSS 改版或没有沟通按钮时可能无法识别，需人工检查姓名和摘要边界；手动添加是备用路径。
- 不按年龄、性别、婚育等敏感属性筛选；结果没有自动排序、自动淘汰或最终招聘决定。
- 已于 2026-09-12 加载到 Chrome，并在真实招聘端推荐列表读取 15 条摘要；抽查首条姓名和摘要边界正确。其他招聘页面布局仍需按实际使用情况核对。
