# BOSS 招聘复核：功能说明

这是招聘端 Chrome 扩展及配套 Codex Skill。当前实现为关键词证据核对，适合已加载候选人列表的初步人工复核。

## 按钮和功能

| 功能 | 实际做什么 | 使用时注意 |
| --- | --- | --- |
| 岗位名称 | 为导出的 CSV 文件命名 | 不会自动切换 BOSS 岗位，也不生成 JD |
| 技能/工作经验 | 每行一个要求，`SQL|数据库查询` 表示同义词 | 按文字匹配，不分析熟练程度 |
| 读取当前列表 | 识别当前页面及同源 iframe 中已渲染的候选人摘要 | 不翻页、不打开详情、不读取未加载简历 |
| 核对要求 | 为每项要求显示命中的原句或“待核实” | “没有 SQL 经验”也可能命中 SQL，需阅读原句 |
| 去重 | 对当前内存中完全相同的摘要不再重复添加 | 不是按姓名去重；摘要变化或刷新后不能保证识别同一人 |
| 人工标记 | 选择“未复核”“待进一步沟通”“暂存” | 只改变扩展内的记录，不操作 BOSS 招聘状态 |
| 备注和过滤 | 为候选人记备注，按人工标记查看记录 | 过滤只影响显示 |
| 手动添加摘要 | 页面识别失败时粘贴候选人姓名/编号和摘要 | 保留原文，不把推断写成事实 |
| 导出 CSV | 导出全部当前记录、标记、备注及关键词证据 | 即使界面过滤了记录，导出仍包含全部记录 |
| 移除此条/清空记录 | 删除扩展内存中的一条或全部记录 | 不删除 BOSS 数据；需要留档时先导出 |

收起面板不会清空记录，但刷新或关闭页面会丢失记录。扩展没有持久化数据库、自动评分、自动打招呼、自动录用或自动淘汰功能。

## 文件在哪里

| 文件 | 负责什么 |
| --- | --- |
| `SKILL.md` | 告诉 Codex 如何安装、使用及解释扩展结果 |
| `assets/recruiter/core.mjs` | 解析要求、匹配原句、生成 CSV |
| `assets/recruiter/panel.js` | 面板交互、页面卡片识别、当前摘要去重和导出 |
| `assets/recruiter/panel.css` | 面板样式 |
| `assets/recruiter/manifest.json` | Chrome 扩展信息和允许加载的 BOSS 页面范围 |
| `assets/recruiter/build.mjs` | 将源码合成为浏览器可加载的扩展 |
| `assets/recruiter/core.test.mjs` | 关键词、边界、敏感条件及 CSV 转义测试 |
| `assets/recruiter/preview.html`、`fixture.html`、`narrow.html` | 本地演示和虚构候选人测试页面 |
| `assets/recruiter-dist/` | 已构建的扩展，Chrome 应加载此文件夹 |
| `assets/LICENSE` | 保留的原项目 MIT 许可与署名 |

## 怎么用

1. 在 Chrome 打开 `chrome://extensions/`，开启开发者模式。
2. 点击“加载已解压的扩展程序”，选择本项目的 `assets/recruiter-dist/`。
3. 登录自己的 BOSS 招聘账号，刷新招聘沟通页面，打开“候选人复核”。
4. 填写要求，读取列表，核对原句，人工标记，最后导出 CSV。

修改源码后，在 `assets/` 目录执行 `node recruiter/build.mjs`，再到 Chrome 扩展页重新加载扩展并刷新 BOSS 页面。安装和更新 Skill 本身不会自动安装或刷新 Chrome 扩展。
